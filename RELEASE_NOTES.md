Готовая пошаговая стратегия «Эпоха держав» для Windows 10/11 x64.

**Как играть:** скачайте `EpokhaDerzhav-Windows-x64.zip`, полностью распакуйте архив и запустите `EpokhaDerzhav.exe`. Устанавливать Python не требуется. Правила доступны внутри игры по клавише **H**.

В версии реализованы карта из 100 провинций, три страны, экономика и исследования, строительство, армии, войны и дипломатия, решения ИИ, сохранение и загрузка, победа и поражение.

Файл `SHA256SUMS.txt` содержит контрольную сумму Windows-архива.
