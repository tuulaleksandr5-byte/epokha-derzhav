ЭПОХА ДЕРЖАВ — Windows 10/11, 64-разрядная версия

1. Скачайте архив и распакуйте его полностью в любую папку.
2. Запустите EpokhaDerzhav.exe двойным щелчком.
3. Выберите страну и нажмите «Начать».

Для готовой сборки установка Python и Pygame не требуется.

Управление:
  Левая кнопка мыши — выбор провинции и действия интерфейса.
  Enter — следующий месяц.
  N — названия провинций.
  T — отображение армий.
  F5 — сохранить игру.
  F9 — загрузить сохранение.
  H — справка по правилам.
  Esc — меню.

Цель: захватите все 100 провинций. Потеря всех провинций — поражение.
Начните со справки H: она объясняет экономику, строительство и войну.

Для запуска из исходного кода:
  Установите Python 3.12 с python.org.
  Откройте терминал в папке игры и выполните:
    python -m pip install pygame==2.6.1
    python main.py
