# Эпоха держав

Пошаговая стратегия на русском языке для ПК: 100 провинций Вороного, три страны и кампания за объединение континента. Один ход равен одному месяцу.

## Скачать готовую игру для Windows

Откройте раздел **Releases** этого репозитория и скачайте **EpokhaDerzhav-Windows-x64.zip** из списка **Assets**. Распакуйте архив полностью и запустите **EpokhaDerzhav.exe**. Установка Python и Pygame для этой сборки не нужна. Поддерживаются Windows 10/11 x64.

Кнопка **Code → Download ZIP** скачивает исходный код. Готовая Windows-игра находится в разделе **Releases**.

## Что есть в игре

- Три страны с разными стартовыми владениями и бонусами.
- Налоги, благосостояние, инвестиции и исследования; грамотность открывает здания.
- Население, экономика, содержание армии и риск отделения недовольных провинций.
- Фермы, мануфактуры, лагеря снабжения, порты, крепости и смотровые башни.
- Найм войск, соседние перемещения, атаки и морские перевозки.
- Война, мир, союзы и торговые договоры с ИИ.
- Победа при захвате всех 100 провинций и поражение при потере всех земель.
- Сохранение и загрузка кампании, встроенная справка по правилам.

Сохранение в Windows находится в `%LOCALAPPDATA%\EpokhaDerzhav\campaign.json`.
Оно автоматически обновляется после смены месяца и при выходе. Кнопка «Новая кампания»
начинает новую историю и заменяет это сохранение.

Первые шаги: во вкладке **Страна** проверьте месячный баланс. В своей провинции
постройте ферму или мануфактуру и наймите войска. Для нападения сначала объявите
войну во вкладке **Дипломатия**, затем выберите свой отряд во вкладке **Армия**,
нажмите **Переместить / атаковать** и укажите соседнюю цель на карте. Прибывшие
войска и новобранцы готовы действовать со следующего месяца.

## Управление

| Действие | Клавиша |
| --- | --- |
| Выбрать провинцию / кнопку | Левая кнопка мыши |
| Следующий месяц | Enter |
| Подписи провинций | N |
| Показать армии | T |
| Сохранить / загрузить | F5 / F9 |
| Справка | H |
| Меню | Esc |

## Запуск исходного кода

Нужны Python 3 и Pygame. Других внешних библиотек игра не использует. Весь игровой код находится в **main.py**; комментарии и интерфейс на русском.

```sh
python -m pip install -r requirements.txt
python main.py
```

## Проверки

```sh
python -m unittest discover -s tests -v
```

## Собрать Windows-версию самостоятельно

В Windows с Python 3.12 x64:

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm --onefile --windowed --name EpokhaDerzhav --collect-all pygame main.py
```

Готовый исполняемый файл появится в **dist/EpokhaDerzhav.exe**. PyInstaller нужен только для сборки.

GitHub Actions выполняет проверки, создаёт EXE и публикует Windows ZIP при отправке тега вида **v1.0.0**. Также можно открыть **Actions → Windows game release → Run workflow**. Исполняемый файл дополнительно проверяется на запуск в Windows перед публикацией.
